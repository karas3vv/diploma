# Дипломная работа

**Поиск изменений в связях между каналами мультивариативного временного ряда**

Репозиторий выпускной квалификационной работы студента 4 курса направления
«Программная инженерия» факультета КНиИТ СГУ. Год защиты — **2027**.

Работа посвящена обнаружению изменений зависимостей между каналами многомерного
временного ряда. Отдельные показатели могут сохранять привычные значения,
хотя их совместное поведение уже изменилось. Исследуется, когда анализ таких
связей помогает обнаруживать смену режима и как отличать её от случайных
колебаний оценок.

## Подход к исследованию

Предполагается строить взвешенные графы связей в последовательных временных окнах:
вершины соответствуют каналам, а веса рёбер — оценкам зависимости между ними.
Основные способы оценки — корреляция Пирсона и взаимная информация.

В исследовании планируется:

- сравнить обнаружение изменений связей с анализом отдельных каналов;
- исследовать линейные и нелинейные зависимости;
- проверить влияние длины окна, шума и неопределённости оценок;
- оценить качество обнаружения, задержку, частоту ложных тревог и время работы;
- проверить подход на синтетических данных с известными изменениями и подходящем
  реальном наборе данных.

Преимущества методов предстоит проверить экспериментально. Изменение
статистической связи само по себе не доказывает неисправность или причинное
влияние одного канала на другой.

## Структура диплома

План диплома включает введение, две основные части, заключение и список источников.

1. **Теоретическая часть:** свойства временных рядов, структурные изменения,
   оценка зависимостей, динамические графы, методы обнаружения, неопределённость,
   критерии качества и обзор исследований.
2. **Практическая часть:** постановка исследования, данные, предобработка,
   выбранная методика, программная реализация, эксперименты, результаты
   и обсуждение ограничений.

Подробные подразделы, содержание каждого пункта и порядок написания описаны
в [THESIS_PLAN.md](THESIS_PLAN.md). План изучения и выполнения задач —
в [TODO.md](TODO.md).

## Сборка документа

Для сборки необходима установка LaTeX с командами `pdflatex` и `bibtex`,
поддержкой русского языка и пакетами из `preamble.sty` и `SCWorks.cls`.

Выполнить из корня репозитория:

```bash
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error course_work.tex
bibtex course_work
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error course_work.tex
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error course_work.tex
```

Последовательность обновляет библиографию, содержание и ссылки. Результат —
`course_work.pdf`; этот файл и промежуточные файлы сборки исключены из Git.

Для актуального документа используйте команды выше: вспомогательный `watch.sh`
сохранён из исходного шаблона и пока ссылается на `main.tex`.
